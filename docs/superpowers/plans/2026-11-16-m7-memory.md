# M7 Project Memory Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (owner pre-authorized inline execution). Steps use checkbox (`- [ ]`) syntax.

**Goal:** vertex outcomes become project episodic memory; the next task gets a relevant slice in its prompt; humans promote episodes into the org-memory repo through PRs.

**Architecture:**
- **Store:** episodes live in the control-plane DB (agent_api), ranked lexically plus by path overlap.
- **Worker:** writes back fail-open and injects the slice into the prompt.
- **Extractor:** a light LLM role turns the result into lessons.
- **Org memory:** a Gitea repo with a reuse catalog and a promote CLI.

**Tech Stack:** FastAPI + SQLAlchemy (agent_api), httpx, LiteLLM (`qwen-coder`), typer, bash/toolbox.

**Spec:** `docs/superpowers/specs/2026-11-16-m7-memory-design.md`

## Global Constraints

- **Episode fields:** kinds `lesson|deploy|postmortem|failure|decision`; title ≤200 characters, body ≤8000 (longer is trimmed, not rejected).
- **Ranking:**
  - +3 per path match;
  - +1 per shared word of 4+ characters, capped at +5;
  - +1 if newer than 7 days;
  - +2 for postmortem/failure;
  - score 0 is dropped; ties go to the newer episode.
- **Slice:** default `limit` 5, max 20. Prompt section header: `Project memory (lessons from earlier tasks — follow them):`, each body cut to 400 characters.
- **Fail-open:** memory errors never fail a vertex; they are audited `memory_skipped`.
- **Extractor:** at most 2 lessons; invalid JSON → none.
- **Org memory:** repo `swarm-lab/org-memory`; promotion PR adds `lessons/<project>-<id>.md`, authored by the operator only.
- **LLM:** z.ai only until its limit; extractor model `qwen-coder`.

## Review Focus

1. **agent_api down at vertex start.** The vertex runs without memory and the prompt is unchanged. Pinned in Task 3.
2. **The extractor returns prose or a fenced JSON block.** Fenced JSON is parsed; prose yields no lessons. Pinned in Task 2.
3. **A slice query with no paths and no words.** It must return [] rather than every episode. Pinned in Task 1.
4. **A huge body (an 8000+ character postmortem).** It is trimmed on write, and the prompt shows ≤400 characters. Pinned in Tasks 1 and 3.
5. **Promoting an unknown episode id.** Clear error, no PR. Pinned in Task 4.
