# M9 Polyglot Dogfood Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (owner pre-authorized inline execution).

**Goal:** a TypeScript service onboarded from a template passes the full corridor with an agent-made change.

**Spec:** `docs/superpowers/specs/2026-11-16-m9-polyglot-design.md`

## Global Constraints

- **Profile `typescript`:** contexts `ci / checks`, `ci / security`. `checks` runs `npm ci` → `npx tsc --noEmit` → `npx eslint .` → `npm test`. `security` is identical to the python profile's.
- **Template `ts-service`:** `package.json` + `package-lock.json` (for `npm ci`), `tsconfig.json`, `eslint.config.mjs`, `src/`, `test/`, `.gitignore` (`node_modules/`, `dist/`). No `node_modules` committed.
- **`done_when`:** `docker run --rm -v "$PWD":/w -w /w node:22-alpine sh -c "npm ci --no-audit --no-fund && npm test"`.

## Review Focus

1. **`npm ci` without a lockfile fails.** The template must ship `package-lock.json`. Test.
2. **`node_modules` or `dist` leaking into a seed or an agent diff.** `.gitignore` covers them; `seed` excludes them. Test.
3. **Re-onboarding an existing repo must not re-seed.** Same as `seed-demo`.
