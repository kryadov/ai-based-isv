# M8 Swarm Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (owner pre-authorized inline execution).

**Goal:** a task becomes a validated vertex graph executed by parallel workers through the corridor, with handoffs, backpressure, metrics and a judge.

**Spec:** `docs/superpowers/specs/2026-11-16-m8-swarm-design.md`

## Global Constraints

- **Planner:** never emits commands. Its paths must lie inside `allowed`. Concurrent vertices get disjoint paths. Any failure falls back to a single vertex.
- **Workers:** `<agent>-w<i>` identity, `<root>/w<i>` workspace.
- **Backpressure:** default `max_pending_merges` 3.
- **Judge:** all vertices `done` + the run `done_cmd` on the merged main → run `done` + a `decision` episode.
- **Text:** English; `*.ru.md` mirrors. No `git add -A`.

## Review Focus

1. **The planner returns cyclic or overlapping parallel paths.** Fallback to a single vertex, never a crash. Pinned in Task 2.
2. **A dependent vertex claimed before its deps are done.** It is never claimed; the control plane already guards this. Pinned in Task 1 by a run-vertices test.
3. **All workers blocked by backpressure.** They resume once HITL drains; there is no deadlock because pending merges are decided by humans or auto-approve. Pinned in Task 3.
4. **The judge on a run with a failed vertex.** The run becomes `failed`, with the reasons. Pinned in Task 4.
5. **A worker process crash in `swarm run`.** The lease expires and another worker takes the vertex; the supervisor reports it. Pinned in Task 4 (supervisor reports a non-zero exit).

- `POST /runs/{id}/status`;
- `GET /metrics`.

- [ ] Write the tests (API): the vertex list with result and deps; status `done`/`failed` with any other value → 422 and an audited verdict; metrics text containing `swarm_vertices{status="queued"}` and `swarm_hitl_pending{kind="merge"}`.

### Task 2: Planner + validation

`planner.py` provides `VertexPlan`, `PlanError`, `validate_plan`, `globs_overlap`, `plan_task`, `fallback_plan`.

- [ ] Write the tests:
  - a valid 3 + 1 plan;
  - an unknown dep, a cycle, too many vertices, a path outside `allowed`, overlapping concurrent paths: each raises `PlanError`;
  - dependent vertices may overlap;
  - `plan_task` parses fenced/bare JSON and falls back on invalid output or HTTP error.
- [ ] FAIL → implement → PASS. Commit.

### Task 3: Worker — handoffs + backpressure

- [ ] Write the tests:

  - with 3 pending merge HITL requests, the worker does not claim and audits `backpressure`; when they drain, it claims.

### Task 4: `swarm` CLI — plan, run, judge
